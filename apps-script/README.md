# '내 연수 정보' 서버 배포 방법 (Google Apps Script)

휴대폰 번호를 입력하면 본인의 **이름 · 연수번호 · 1일차 분임 · 2일차 AI 분임 · 호차**만 보여 주는 기능의 서버 쪽입니다.
개인정보(이름·연락처)는 **구글 시트에만** 두고, GitHub에는 올리지 않습니다. 이 폴더의 `Code.gs`에는 개인정보가 없습니다.

## 1. 시트 만들기
1. 구글 드라이브에서 새 **구글 시트**를 만들고 이름을 `5급연수_내정보조회` 등으로 정합니다. (공유하지 말고 본인만 볼 수 있게 둡니다.)
2. 담당자 PC의 `메뉴만들기/내정보조회_비공개/명단_시트용.csv`를 시트에 가져옵니다.
   - 시트 메뉴 **파일 → 가져오기 → 업로드** → 파일 선택 → 가져오기 위치 **현재 시트 바꾸기** → 가져오기.
3. 첫 줄이 `연수번호 | 이름 | 연락처 | 1일차분임 | 2일차AI분임 | 호차`인지 확인합니다. (연락처 앞의 0이 없어져도 서버가 알아서 맞춥니다.)
   - 강사·멘토 이름 열은 넣지 않습니다.

## 2. 스크립트 붙여넣기
1. 시트 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
2. 기본 코드를 모두 지우고 `Code.gs` 내용을 붙여넣은 뒤 저장(💾)합니다.

## 3. 웹앱으로 배포
1. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 유형 **웹 앱** 선택.
2. 설정
   - 설명: `내 연수 정보`
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
3. **배포**를 누르고 권한 허용(처음 한 번, "안전하지 않은 페이지" 경고가 나오면 고급 → 이동)을 합니다.
4. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.

> 코드를 고친 뒤에는 **배포 관리 → 편집(연필) → 새 버전 → 배포**를 해야 반영됩니다. (URL은 그대로 유지)

## 4. 안내 페이지에 연결
`index.html`에서 아래 한 줄의 따옴표 안에 위 웹 앱 URL을 넣습니다.

```js
var ME_API='';   // ← 여기에 URL
```

## 5. 동작 확인
- 웹 앱 URL을 브라우저로 열면 `{"ok":true,"service":"promo5-me"}`가 보이면 정상입니다.
- 안내 페이지 4쪽 '내 연수 정보'에서 본인 번호를 입력해 확인합니다.
- 등록되지 않은 번호는 "등록된 번호가 아닙니다"가 나옵니다.
- 10분 안에 틀린 번호가 60번 넘으면 잠시 조회가 막혀 번호 무작위 대입을 막습니다.

## 6. 연수가 끝나면
- 시트의 연락처 열을 지우거나 시트를 삭제하고, 웹 앱 배포를 **보관처리**(배포 관리 → 보관)합니다.
